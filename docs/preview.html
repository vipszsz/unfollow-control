Roadmap

Seis fases. O app roda inteiro no seu PC: não tem servidor nem login, e o próprio app é bloqueado para não acessar a internet. Os links de perfil abrem no seu navegador, onde você já está logado no Instagram.

fase_01 · fundação

Base e visual

O esqueleto do app e a identidade visual.

  • Vite + TypeScript dentro do Electron, sem acesso à rede
  • Tema escuro (padrão) e claro, vidro e degradês com grão
  • Scroll, menus, tooltips e toggles próprios, nada nativo
  • Português e inglês desde o início
fase_02 · importar

Zip e “Como exportar”

Arrastar o zip e pronto.

  • Lê seguidores, seguindo, pendentes e unfollows recentes
  • Guia “Como exportar” com passos ilustrados
  • Avisa se o zip veio incompleto ou em HTML
  • Dados guardados só no PC, com botão “Apagar tudo”
fase_03 · listas

Modo lista

As quatro abas, 10 contas por página.

  • Não me seguem · Mútuos · Me seguem · Pendentes
  • Busca, ordenação por data e filtros por etiqueta
  • Abrir perfil e marcar como revisada
  • Atalhos de teclado (J/K para navegar, O para abrir)
fase_04 · swipe

Modo swipe e etiquetas

Uma conta por vez, no estilo Tinder.

  • Arrastar com física de mola (skill da Apple)
  • ← deixar de seguir · → manter · ↑ pular
  • Etiquetas coloridas: Amigo, Talvez, Marca/Artista
  • Contas com etiqueta “manter” somem das próximas triagens
fase_05 · histórico

Histórico e busca

Comparar exports e buscar qualquer conta.

  • Quem deixou de te seguir e quem passou a seguir
  • Meta diária de unfollows, com contador
  • Busca “quem eu sigo que segue @x” (mockup abaixo)
fase_06 · entrega

Empacotar e compartilhar

Para você e para os amigos.

  • .exe portátil para Windows: um arquivo, sem instalação
  • Versão em HTML único para quem usa Mac
  • Repositório no GitHub com README e Release
  • Ícone do app

Para aprovar

Três propostas que mudam o comportamento do app.

1 · O swipe decide; uma fila executa

O app não consegue dar unfollow sozinho. Se cada swipe para a esquerda abrisse o navegador, o ritmo do swipe se perderia. Proposta: no swipe você só decide, e as contas vão para uma Fila de unfollow. Depois você percorre a fila com um botão “Abrir próximo”, que abre o perfil, e confirma. É o fluxo de limpeza do Google Fotos: marcar primeiro, executar depois.

2 · Etiquetas

Amarelo e âmbar são parecidos, então cada cor ganha um significado claro. Os nomes podem ser editados no app.

Amigo · manterTalvez · rever depoisMarca / Artista · manterFila de unfollow

3 · Electron, .exe portátil

É um arquivo único de uns 90 MB, sem instalação. Os dados ficam no seu PC (na pasta do app). Como o .exe não tem assinatura digital, que custa caro, o Windows mostra “O Windows protegeu o computador” na primeira vez. Basta clicar em “Mais informações → Executar assim mesmo”. Vou explicar isso no README para os amigos.

4 · Repositório no GitHub

Público, para os amigos baixarem pela página de Releases e qualquer pessoa poder conferir que o app não envia nada? Ou privado por enquanto?

Busca: quem eu sigo que segue @x

Mockup interativo. Digite na busca (por exemplo “estudio”) ou use as setas e o Enter. A busca usa as suas listas para mostrar a relação com a conta. Para ver quem segue essa conta, o app abre o perfil no seu navegador, onde aparece “Seguido por…”.
